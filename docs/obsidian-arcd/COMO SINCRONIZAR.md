# Como sincronizar

Esta pasta já é um vault compatível com Obsidian.

## Opção recomendada

1. Disponibilize o vault do OneDrive como arquivo `.zip` nesta conversa; ou
2. Conecte uma credencial Microsoft com acesso explícito à pasta; ou
3. Copie estes arquivos para uma pasta do vault sincronizada pelo OneDrive.

Mescle a pasta `docs/obsidian-arcd` no vault. Não substitua a pasta `.obsidian`.

## Automação futura

Para aprendizado contínuo, o app pode gerar uma nota de decisão após cada mudança aprovada e indexar o vault para busca semântica. A gravação automática deve exigir revisão antes de alterar uma nota existente.
